# 01 › Development Process

Learn how to use Claude Code at **every stage** of building an application.

## Stages

```
Project Start
      │
      ▼
🟢 [Planning](./01-planning.md)
      │  Architecture decisions, task breakdown, plan mode
      ▼
🟢 [Development](./02-development.md)
      │  Writing code, refactoring, file operations
      ▼
🟡 [Test & Debug](./03-test-and-debug.md)
      │  Writing tests, debugging, log analysis
      ▼
🟡 [Code Review](./04-code-review.md)
      │  PR review, diff analysis, comment generation
      ▼
🔴 [Deployment](./05-deployment.md)
         CI/CD integration, environment management
```

## Which Stage Am I At?

| I'm doing | Go to |
|---|---|
| Designing architecture, breaking down tasks | [Planning](./01-planning.md) |
| Actively writing code | [Development](./02-development.md) |
| Writing tests or debugging | [Test & Debug](./03-test-and-debug.md) |
| Opened a PR, doing review | [Code Review](./04-code-review.md) |
| In CI/CD or deploy process | [Deployment](./05-deployment.md) |
