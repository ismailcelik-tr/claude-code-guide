# 00 › Getting Started

If you're using Claude Code for the first time, start here.

---

## What is Claude Code?

Claude Code is Anthropic's CLI-based AI tool. It runs in the terminal, reads and writes files, executes commands, and supports you like a real development partner.

**What it is not:** Just a conversational chatbot. It's an agent with access to your codebase that uses tools.

---

## Installation

```bash
npm install -g @anthropic-ai/claude-code
```

First run:

```bash
claude
```

You'll be prompted to log in with your Anthropic account.

---

## Philosophy: Start Minimal

> No matter how powerful the tool, don't set it up before you need it.

You don't need to configure everything at once. Follow this order:

1. **Manual prompts** — use Claude freely first, observe what you need
2. **CLAUDE.md** — add it when Claude asks the same thing twice
3. **Hook** — add it when you notice a repeated manual step
4. **Custom command** — add it when you've typed the same prompt more than three times

Each step should be triggered by a real friction point — not a hypothetical need.
