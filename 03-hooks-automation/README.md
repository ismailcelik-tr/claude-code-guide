# 03 › Hooks & Automation

Automatically run commands before or after specific actions in Claude Code.

---

## What is a Hook?

Before or after Claude calls a tool, a shell command you define runs automatically. This lets you:
- Run lint on every save
- Block dangerous commands
- Send notifications
