## Aşamalar

```
Proje Başlangıcı
      │

      │  Mimari kararlar, görev dağılımı, plan modu
      ▼
🟢 [Geliştirme](./02-gelistirme.tr.md)
      │  Kod yazma, refactor, dosya işlemleri

      │  Test üretme, hata ayıklama, log analizi

      │  PR inceleme, diff analizi, yorum üretme

         CI/CD entegrasyonu, ortam yönetimi
```
