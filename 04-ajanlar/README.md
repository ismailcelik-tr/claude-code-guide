# 04 › Ajanlar

Claude Code'un Agent tool ile başka ajanlara görev delege etmesi.

---

## Neden Ajan Kullanılır?

- Bağımsız görevleri **paralel** çalıştırmak
- Ana konuşmanın bağlamını koruyarak derin araştırma yaptırmak
- Uzmanlaşmış iş için doğru araç setini kullanmak
