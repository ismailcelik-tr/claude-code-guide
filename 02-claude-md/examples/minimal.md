# Template: Minimal CLAUDE.md

For small projects or quick starts.

---

```markdown
# [Project Name]

## What It Does
[1-2 sentences]

## Tech Stack
- [Language / Framework]
- [Database / Service]

## Commands
- [development command]
- [test command]

## Rules
- [2-3 most important rules]
```

---

## Usage

Copy this template and save it as `CLAUDE.md` in the root of your project. Fill in the parts in square brackets.
