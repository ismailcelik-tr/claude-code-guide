## Bu Bölümü Nasıl Kullanmalısın?

Her senaryo şu yapıyı izler:

1. **Durum** — ne ile karşı karşıyasın
2. **Adım adım** — hangi Claude Code araçlarını hangi sırayla kullanırsın
3. **Kullanılan prompt'lar** — gerçek, kopyalanabilir örnekler
4. **Tuzaklar** — bu senaryoda sık yapılan hatalar
