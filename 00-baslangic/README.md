# 00 › Başlangıç

Claude Code'u ilk kez kullanıyorsan buradan başla.

---

## Claude Code Nedir?

Claude Code, Anthropic'in geliştirdiği CLI tabanlı yapay zeka aracıdır. Terminal üzerinden çalışır, dosya okur/yazar, komut çalıştırır ve seni gerçek bir geliştirme ortağı gibi destekler.

**Ne değildir:** Sadece sohbet eden bir chatbot değil. Kod tabanına erişimi olan, araç kullanan bir ajandır.

---

## Kurulum

```bash
npm install -g @anthropic-ai/claude-code
```

İlk çalıştırma:

```bash
claude
```

Anthropic hesabınla giriş yapman istenecek.
